# Тесты игровой логики

Тесты проверяют публичное поведение `web/game.js` и запускаются встроенным test runner Node.js. Внешние зависимости не нужны.

## Запуск

Из корня репозитория:

```bash
node --test web/tests/game.test.js
```

В наборе 21 тест. Он покрывает:

- начальное состояние, первый ход X и чередование X/O;
- победу по всем 8 линиям: 3 строки, 3 столбца и 2 диагонали;
- победу X и O, включая победу на последней клетке;
- ничью и полный матч от `reset()` до терминального состояния;
- запрет хода в занятую клетку, после окончания игры и с некорректным индексом;
- `reset()`, `getStatus()` и сохранение текущего игрока после победы.
