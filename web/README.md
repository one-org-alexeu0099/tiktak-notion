# ttt
1. Открой `index.html` в Chrome, Firefox, Safari или Edge.
2. Сборка и зависимости не нужны: проект использует vanilla JS.
3. Автотесты будут запускаться из каталога `/web/tests` после этапа S1.
4. Сейчас каталог `/web/tests` содержит только подготовленную заглушку.
5. Артефакты именуются по схеме `ttt_v1_sX_aN`.

## Структура проекта
- `/web` — клиент.
- `/web/tests` — тесты.
- `/server` — зарезервировано под v2.

## Коммиты
- Формат: `type(sN): что сделано`.
- Допустимые типы: `feat`, `fix`, `test`, `chore`, `docs`.
- Одна задача = один коммит.
