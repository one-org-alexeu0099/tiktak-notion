# Крестики-нолики (tiktak-notion)

## О проекте

Статический vanilla JS-проект «Крестики-нолики» для игры двух человек на одном устройстве.
Репозиторий также используется как полигон для процесса управления разработкой через Notion и агентов.

Репозиторий: https://github.com/one-org-alexeu0099/tiktak-notion
- [AGENTS.md](AGENTS.md) — стартовый указатель для агентов.

## Структура проекта

- `web/index.html` — HTML-страница игры.
- `web/app.js` — UI и обработчики действий пользователя.
- `web/game.js` — игровая логика и браузерный API `window.TTTGame`.
- `web/styles.css` — стили и адаптивная раскладка.
- `web/tests/game.test.js` — тесты игровой логики.
- `web/tests/README.md` — описание тестов и команды запуска.
- `/server` зарезервирован под v2; в текущей версии каталога нет.

Сборка и внешние зависимости не нужны.

## Запуск

Из корня репозитория доступны штатные команды:

```bash
make dev
make test
make check
```

### Запуск в браузере

Штатный браузерный стенд запускается из корня репозитория:

```bash
make dev
```

Открой http://127.0.0.1:18765/index.html. После проверки останови сервер в терминале.

Резервный ручной запуск без `make`:

```bash
python3 -m http.server 18765 --directory web
```

## Тесты

В проекте 21 автотест игровой логики. Запуск из корня репозитория:

```bash
node --test web/tests/game.test.js
```

Тесты покрывают начальное состояние, очередность ходов, все 8 победных линий, ничью, занятые и некорректные клетки, ходы после завершения игры, сброс, `getStatus`, победу на последней клетке и полный матч.
